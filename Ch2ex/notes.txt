Creating new MVC projects:

NOTE: The book uses VisualStudio 2013. I'm on VS2022: here is an approximation of what the author describes
1. New project
2. Use template: ASP.NET Web Application (.NET Framework)
3. Project name: PartyInvites
   Location: <workarea root>\ChXex
   Solution Name: PartyInvites
   Framework: select the latest .NET Framework v4.8
4. MVC

There is no longer an option for an 'empty' solution, just accept the minimal boilerplate that it provides.
bootstrap is preinstalled with the template (a newer version than the book specifies)

NuGet:
NuGet UI: Tools | Library Package Manager | Manage NuGet Packages for Solution
NuGet CLI: Tools | Library Package Manager | Package Manager Console
Example bootstrap install:
Download the package and add it to the project:
e.g. latest:
Install-Package bootstrap
e.g. v3.0.0:
Install-Package -version 3.0.0 bootstrap
